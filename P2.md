# Words - Phase 2: Next.js Frontend Walkthrough

This document highlights the visual design systems, component architecture, and interactive features implemented in the `frontend/` folder for the **Words** quote archive.

---

## 🎨 1. Premium Visual & Styling System

The user interface uses **Tailwind CSS v4** with elegant typography pairings:

- **Serif Font:** [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) - applied to the quotes for a refined, classic, literary look.
- **Sans-serif Font:** [Inter](https://fonts.google.com/specimen/Inter) - used for all clean UI labels, metadata tags, search components, and AI context blocks.

### Glassmorphic Dark Mode Aesthetics

The app adapts dynamically to the system dark mode:

- **Light Theme:** Off-white backgrounds (`bg-zinc-50`), charcoal typography (`text-zinc-900`), and warm amber highlights.
- **Dark Theme:** Zinc-950 absolute dark backgrounds (`bg-[#08080a]`), white text (`text-zinc-50`), and highly subtle glassmorphic blurs (`backdrop-blur-md`).

## 🧩 2. Modular Component Architecture

The frontend is built using standard React and Next.js (App Router) architectural patterns:

```
src/
├── app/
│   ├── globals.css      # Custom styles and scrollbar animations
│   ├── layout.tsx       # Typography variables and SEO tags
│   └── page.tsx         # Server Component (Data Fetching & Fallbacks)
├── components/
│   ├── AddQuoteModal.tsx # Form modal with real-time AI Pipeline Status loader
│   ├── MasonryGrid.tsx  # Pure CSS Pinterest-style masonry grid
│   ├── QuoteCard.tsx    # Smoothly expanding item card
│   └── QuotesArchive.tsx# Client controller (Search, tags, stats)
└── types/
    └── index.ts         # Shared TypeScript interfaces
```

## ⚡ 3. Premium Interactive Features

### A. The "Dive Deeper" Grid Expansion

Instead of hard-layout shifts, the expansion of details (author, source, tags, related quotes, and AI contexts) utilizes the CSS **CSS Grid Rows Transition technique** (`grid-rows-[0fr]` ➔ `grid-rows-[1fr]`). This ensures a buttery-smooth pixel transition down the card without any abrupt popping.

```typescript
<div className={`grid transition-all duration-500 ease-in-out ${
  isExpanded ? "grid-rows-[1fr] opacity-100 mt-5" : "grid-rows-[0fr] opacity-0"
}`}>
  <div className="overflow-hidden">
    {/* Detailed Content */}
  </div>
</div>
```

### B. O(1) Related Quotes Lookup & Inter-Card Navigation

To display the brief text of similar quotes without spawning multiple parallel HTTP calls:

1. The **Server Component** loads all quotes in a single fetch.
2. The parent `MasonryGrid` creates a fast Map lookup index: `const quotesMap = new Map(quotes.map(q => [q.id, q]))`.
3. It passes resolved similar quotes directly to the card: `relatedQuotes={quote.related_quote_ids.map(id => quotesMap.get(id))}`.
4. **Interactive Highlighting:** Clicking on a similar quote inside an expanded card automatically scroll-centers the target quote smoothly into view and blinks it with a golden highlight ring!

### C. The Progressive AI Pipeline Modal

When submitting raw text, rather than showing a generic loading spinner, the **AddQuoteModal** renders a live status tracker depicting the state of the Cloudflare Workers AI pipeline in real-time:

1. **Vector Ingestion:** Status of text-embedding generation (`@cf/baai/bge-base-en-v1.5`).
2. **Fuzzy Deduplication:** Scan of Vectorize index with threshold `>0.95`.
3. **AI Enrichment:** Metadata mapping using `llama-3-8b-instruct`.
4. **Relational Storage:** Final database save to Cloudflare D1.

If the worker reports a `409` conflict, the deduplication tracker turns red, alerting the user that the exact or a highly similar quote has already been archived.

## 🚀 4. Execution Commands

From the project root workspace, you can easily control both the frontend Next.js dev server and the backend Cloudflare Worker:

```bash
# Install everything (if needed)
bun install

# Start Next.js Frontend Server (http://localhost:3000)
bun run dev

# Start Cloudflare Worker Local Dev API (http://localhost:8787)
bun run start:worker
```
