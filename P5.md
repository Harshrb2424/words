# Words - Phase 5: Dynamic OpenGraph Image Generation, Metadata Base Resolution, and Rich Social Previews

This document records the architectural details, configurations, and implementation notes for the Phase 5 milestones of the **Words** quote sanctuary.

---

## 🖼️ 1. Dynamic OpenGraph Preview Images (Edge-Native)

To enable visually rich, dynamic previews when quotes or the main homepage are shared on social media and communication platforms (WhatsApp, Telegram, Slack, Twitter/X, Facebook), we integrated Next.js dynamic image generation utilizing Satori and the Edge Runtime.

### A. Root Homepage Image (`frontend/src/app/opengraph-image.tsx`)
* **Resolution:** 1200 x 630 pixels (standard OpenGraph landscape ratio).
* **Design Philosophy:** Minimalist dark aesthetic matching the sanctuary branding. Renders a deep charcoal/black background (`#09090b`), large stylized amber-tinted quote marks, a dominant gold logo header, and the tech stack attribution signature.
* **Compatibility:** Natively designated to run on the `edge` runtime.

### B. Dynamic Quote Page Image (`frontend/src/app/quote/[slug]/opengraph-image.tsx`)
* **Endpoint Resolution:** Dynamically processes parameters (async-safe resolution compatible with Next.js router conventions) and extracts the quote's numeric database identifier from its URL slug.
* **Server-to-Server Data Load:** Initiates a backend API fetch to the Cloudflare Worker carrying the secure `"x-words-internal": "words-frontend"` identification header.
* **Dynamic Styling & Colors:**
  * Extracts the quote's text, author, and source.
  * Adjusts font sizes dynamically based on quote character count (downscaling font sizes for longer text to prevent clipping).
  * Automatically parses the quote's custom theme hex code to render a top-center ambient radial background glow matching the quote's dynamic accent signature.

## 🔗 2. OpenGraph and Twitter Metadata Enlivement

Next.js App Router metadata structures were upgraded to ensure crawler indexability and social card resolution:

### A. Metadata Base Resolution (`frontend/src/app/layout.tsx`)
Crawlers like WhatsApp and Slack require fully qualified absolute URLs in the `<meta property="og:image" ...>` tags.
* **Configuration:** Added `metadataBase` to the global layout metadata structure:
  ```typescript
  metadataBase: new URL("https://words.harshrb.in"),
  ```
* **Benefit:** Ensures all relative image references (including dynamically generated sibling `opengraph-image` routes) are compiled into absolute URL pointers.

### B. Rich Page Meta Bindings (`frontend/src/app/quote/[slug]/page.tsx`)
* **Metadata Structure:**
  * **Absolute Title:** Bypasses layout title templates to output custom clean strings (`“Quote snippet...” — Author | Words Sanctuary`).
  * **OpenGraph Specifics:** Sets `url`, `siteName` (`Words Sanctuary`), and `type` (`article`).
  * **Twitter Cards:** Configured as `summary_large_image` to render full-bleed banner layouts in the timeline feed.

## 📥 3. Bulk Ingestion and Precise Pipeline Tracker

To enhance quote creation, the **Whisper a Quote** creation flow was updated to support batch processing:
* **Multi-Quote Dynamic Forms:** Allows curators to add multiple quotes dynamically with an interactive array state, letting them insert/prune entries as they compile.
* **Workers Bulk API Endpoint Integration:** If multiple quotes are present, the client batch submits them to `POST /api/quotes/bulk`. Quotes are separated by double newlines (`\n\n`), then processed sequentially on the Cloudflare edge to avoid rate-limiting limits.
* **Precise 6-Step Pipeline Tracker:** Reconfigured the loader to match the backend Worker's exact execution timeline:
  1. **Web Search RAG Retrieval:** Fetches DuckDuckGo HTML queries for source context.
  2. **AI Enrichment & Cleanup:** Contextual Llama 3 formatting and metadata/accent color assigning.
  3. **Embedding Vector Generation:** Generating 768-dimensional vectors via `@cf/baai/bge-base-en-v1.5`.
  4. **Fuzzy Deduplication Scan:** Blocking duplicates at a `>0.95` cosine similarity score inside Cloudflare Vectorize.
  5. **Relational SQL Storage:** Inserting metadata details and top 3 similar quote links into D1.
  6. **Vector Vectorize Ingest:** Upserting embedding values to Vectorize.
* **Error-Highlighting & Buffer Sync:** Highlighting exact failure locations (e.g., Fuzzy Deduplication Scan fails on 409 duplicate errors), automatically syncs successfully parsed quotes to local storage buffers, and redirects users to the created quotes.

## 🎨 4. Advanced Canvas Customizations (Wallpaper Studio)

Upgraded **Wallpaper Studio** with elite design coordinates, enabling high-fidelity custom graphic creation:
* **Mobile-Responsive Viewport Preview:** Pinning the preview canvas size on mobile viewports so that it fits the screen beautifully while keeping the Customizer panel fully scrollable underneath.
* **Typography Margins & Scaling:**
  * **Side Padding slider:** Let users adjust left/right content margins from `0%` to `40%` dynamically.
  * **Font scale multiplier:** Relative size scale slider from `50%` to `200%` of calculated base sizes.
* **Dynamic Background Image URL Loader:** Loads remote image inputs. Employs `img.crossOrigin = "anonymous"` to prevent tainted canvas downloads.
* **Cover-Image Math:** Automatically crops and covers background images center-aligned to match target presets (PC FHD/4K, Mobile UHD/HD, Instagram Square/Portrait, Twitter/X Post).
* **Graphic Filters (Blur & Dim Overlay):** Isolates filters to background layers (using `ctx.filter` commands) leaving text layers sharp:
  * **Blur Slider** (`0px` to `40px`).
  * **Overlay Darkness/Brightness** (`20%` to `100%`).
  * **Monochrome & Sepia** effects.
  * Defaults text styling colors to bright white/silver for absolute legibility on image layers.
